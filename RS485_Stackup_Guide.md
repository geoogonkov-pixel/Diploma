# Настройка Stackup в EM Structure: пошаговая инструкция

## Проблема

Вы создали EM Structure, но не можете настроить Stackup (слои платы). Без правильного Stackup EM-симуляция невозможна.

---

## Способ 1: через диалог Enclosure/Stackup (основной)

### Шаг 1. Откройте EM Structure

Дважды щёлкните по вашей EM Structure в дереве проекта (`EM Structures → RS485_EM`). Откроется EM-редактор — пустое поле с сеткой.

### Шаг 2. Откройте настройки Enclosure

Один из способов (попробуйте по порядку — интерфейс зависит от версии AWR):

**Способ A:**
- В меню: **Options → EM Structure Options** (или просто **Options → Enclosure**)
- Или: правой кнопкой по пустой области EM-редактора → **Enclosure** или **EM Options**

**Способ B:**
- В дереве проекта раскройте **EM Structures → RS485_EM → Enclosure**
- Дважды щёлкните по **Enclosure**

**Способ C:**
- В EM-редакторе внизу может быть панель с вкладками. Ищите вкладку **Stackup** или **Substrate** или **Material Stackup**

**Способ D:**
- В меню EM-редактора: **Edit → Substrate Stackup** или **Edit → Material Stackup**

### Шаг 3. Откроется диалог Enclosure / Substrate

Это окно с таблицей слоёв. Обычно выглядит так:

```
┌────────────────────────────────────────────────┐
│  Enclosure / Material Stackup                  │
│                                                │
│  Cover (top boundary)     [Open/PEC/PMC]       │
│                                                │
│  ┌──────────────────────────────────────────┐  │
│  │ Layer 3: Metal    Cu  T=0.035 mm         │  │  ← сигнальный слой
│  ├──────────────────────────────────────────┤  │
│  │ Layer 2: Dielectric  Er=4.6  H=1.5 mm   │  │  ← FR-4
│  ├──────────────────────────────────────────┤  │
│  │ Layer 1: Ground   PEC                    │  │  ← земля
│  └──────────────────────────────────────────┘  │
│                                                │
│  Bottom boundary          [PEC/Open]           │
│                                                │
│  [Add Layer] [Remove Layer] [OK] [Cancel]      │
└────────────────────────────────────────────────┘
```

### Шаг 4. Настройте слои

По умолчанию может быть только 1 или 2 слоя. Вам нужно **3 слоя**.

**Если слоёв мало — добавьте:**
- Нажмите **Add Layer** (или **Insert Layer**) столько раз, сколько нужно.

**Настройте каждый слой (снизу вверх):**

#### Нижний слой: Ground Plane

| Параметр | Значение |
|----------|----------|
| Type / Material | **Conductor** или **Ground** или **PEC** |
| Name | `Ground` (или оставьте по умолчанию) |
| Thickness | `0` мм (идеальный проводник) или `0.035` мм |

Это земляная плоскость — нижний электрод.

#### Средний слой: Диэлектрик (FR-4)

| Параметр | Значение |
|----------|----------|
| Type | **Dielectric** |
| Er (εr) | `4.6` |
| Tand (Loss Tangent) | `0.02` |
| Thickness / Height | `1.5` мм |
| Name | `FR4` (или оставьте по умолчанию) |

Это основа платы — стеклотекстолит между дорожками и землёй.

#### Верхний слой: Сигнальный металл

| Параметр | Значение |
|----------|----------|
| Type | **Conductor** или **Metal** |
| Material | **Copper** (или задайте вручную: Rho=1, σ по умолчанию) |
| Thickness | `0.035` мм |
| Name | `Signal` (или оставьте по умолчанию) |

На этом слое вы будете рисовать дорожки.

### Шаг 5. Настройте границы (Cover / Bottom)

- **Cover (верх):** `Open` или `Approximate Open` (воздух над платой)
- **Bottom (низ):** `PEC` или `Ground` (идеальная земля)

### Шаг 6. OK

Нажмите **OK** или **Apply**. Stackup настроен.

## Способ 2: используйте STACKUP элемент из схемы

Вы уже создали STACKUP (SUB2) в вашей схеме. Его можно привязать к EM Structure:

### Вариант A: через EXTRACT

В вашем EXTRACT-блоке есть параметр **STACKUP**. Если он пустой (`STACKUP=""`):

1. Дважды щёлкните по EXTRACT в схеме.
2. Найдите параметр **STACKUP**.
3. Введите имя: `SUB2` (имя вашего STACKUP из схемы).
4. OK.
5. Нажмите F8 — EXTRACT создаст EM Structure с правильным Stackup автоматически.

### Вариант B: привязка к EM Structure

1. Правой кнопкой по EM Structure → **Options**.
2. Найдите параметр **STACKUP** или **Substrate**.
3. Выберите `SUB2` из списка.
4. OK.

## Способ 3: если ничего не помогает — через дерево проекта

### Шаг 1

В дереве проекта:
```
EM Structures
  └── RS485_EM
       └── Enclosure    ← дважды щёлкните здесь
            └── ...
```

### Шаг 2

Откроется диалог **Enclosure Properties**. Здесь:

**Вкладка Stackup (или Substrate):**

В таблице слоёв вы увидите строки. Каждая строка — слой. Редактируйте ячейки таблицы:

| # | Name | Type | Material | Er | Tand | Thickness |
|---|------|------|----------|----|------|-----------|
| 1 | Ground | Conductor | PEC | — | — | 0 |
| 2 | FR4 | Dielectric | — | 4.6 | 0.02 | 1.5 mm |
| 3 | Signal | Conductor | Copper | — | — | 0.035 mm |

**Вкладка Enclosure (или Boundary):**

| Параметр | Значение |
|----------|----------|
| X dimension | 5 mm |
| Y dimension | 32 mm |
| Top cover | Open |
| Bottom cover | PEC |

### Шаг 3

**OK** → Stackup настроен.

## Способ 4: если интерфейс сильно отличается (AWR DE 22.1)

Вижу по заголовку окна, что у вас **AWR DE версия 22.1** (не 17). В 22.1 интерфейс Stackup может выглядеть иначе:

### Через меню EM-редактора:

1. Откройте EM Structure (двойной щелчок).
2. Меню: **EM → Substrate / Stackup** или **Edit → Stackup**.
3. Или: на панели инструментов EM-редактора найдите кнопку с изображением слоёв (стопка пластин).

### Через правый клик:

1. Правой кнопкой по пустой области EM-редактора.
2. Ищите: **Substrate Properties**, **Stackup Setup**, **Material Stackup**, **Enclosure Properties**.

### Через свойства EM Structure:

1. В дереве → правой кнопкой по `RS485_EM` → **Properties** (не Options!).
2. Вкладка **Substrate** или **Stackup**.

---

## Как проверить, что Stackup настроен правильно

После настройки в EM-редакторе вы должны видеть:

1. **В панели слоёв** (выпадающий список вверху EM-редактора) — несколько слоёв на выбор. Сигнальный слой (Signal / Metal) должен быть выбираемым.

2. **При рисовании прямоугольника** — он рисуется на выбранном слое. Цвет прямоугольника зависит от слоя.

3. **В 3D-виде** (если доступен: View → 3D View) — видно многослойную структуру.

## Если совсем не получается

Попробуйте **альтернативный путь**: не создавайте EM Structure вручную, а исправьте EXTRACT в схеме:

1. В схеме дважды щёлкните по блоку **EXTRACT**.
2. Параметр **STACKUP**: введите `SUB2`.
3. Убедитесь, что **EM_Doc** имеет имя (например, `EM_Extract_Doc`).
4. Убедитесь, что **Simulator** = `AXIEM`.
5. OK.
6. **F8** — EXTRACT должен автоматически создать EM Structure с геометрией MCLIN, правильным Stackup и портами.
7. В дереве появится новая EM Structure под именем из EM_Doc.

Этот путь проще, потому что EXTRACT сам берёт геометрию из MCLIN и подложку из STACKUP.
