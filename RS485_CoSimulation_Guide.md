# Как связать EM Structure и электрическую схему (Co-simulation)

## Суть задачи

У вас есть:
1. **Электрическая схема** (Schematic) — PORT1, PORT2, MCLIN, R3(120Ом), C1, C2, PORT3, PORT4
2. **EM Structure** (`RS485`) — два прямоугольника (дорожки), 4 порта, AXIEM

Нужно: заменить MCLIN в схеме на результаты EM-модели, чтобы получить точные S-параметры с учётом реальной электромагнитной физики.

---

## Способ 1: EM Structure как подсхема (рекомендуемый)

### Шаг 1. Создайте новую схему

В дереве проекта → **Circuit Schematics** → правой кнопкой → **New Schematic**.
- Name: `RS485_CoSim`
- OK

### Шаг 2. Вставьте EM Structure как элемент

1. В Elements Browser (правая панель) раскройте: **Project → Subcircuits**.
2. Найдите `RS485` (имя вашей EM Structure).
3. Перетащите на лист схемы.

EM Structure появится как **прямоугольный блок** с 4 портами (1, 2, 3, 4). Он заменяет MCLIN — внутри него AXIEM уже рассчитал S-параметры из реальной геометрии дорожек.

### Шаг 3. Подключите элементы вокруг

Соберите ту же обвязку, что в вашей основной схеме:

```
PORT1 (Z=60) ── Pin1 ──┐                       ┌── Pin3 ─┬─ C1(15пФ) ── PORT3 (Z=12kΩ)
                        │                       │         │
                        │   RS485 (EM блок)     │    R3(120Ω)
                        │                       │         │
PORT2 (Z=60) ── Pin2 ──┘                       └── Pin4 ─┴─ C2(15пФ) ── PORT4 (Z=12kΩ)
```

Конкретно:
1. Добавьте **PORT** (P=1, Z=60) → соедините с выводом 1 блока RS485.
2. Добавьте **PORT** (P=2, Z=60) → соедините с выводом 2.
3. Добавьте **RES** (R3=120 Ом) между выводами 3 и 4.
4. Добавьте **CAP** (C1=1.5e-05 мкФ) от вывода 3 → **PORT** (P=3, Z=12000).
5. Добавьте **CAP** (C2=1.5e-05 мкФ) от вывода 4 → **PORT** (P=4, Z=12000).
6. Добавьте **GND** где нужно.

### Шаг 4. Создайте графики

1. **Graphs** → New Graph → Rectangular → `CoSim_S11`.
2. Add Measurement → Data Source: `RS485_CoSim` → S(1,1), DB.
3. Повторите для S(3,1), S(2,1) и т.д.

### Шаг 5. Запуск

Нажмите **F8**.

AWR сначала использует S-параметры из EM-модели (уже рассчитаны AXIEM), затем рассчитает полную схему с терминатором, ёмкостями и портами.

## Способ 2: сравнение на одном графике

Можно сравнить результаты circuit-level модели (MCLIN) и EM-модели на одном графике.

### Шаг 1. Откройте существующий график

Например, Graph 6 (DB(S[1,1])).

### Шаг 2. Добавьте второе измерение

Правой кнопкой внутри графика → **Add Measurement**:
- Data Source: `RS485_CoSim` (новая схема с EM-блоком)
- Measurement: S(1,1), DB
- OK

Теперь на одном графике:
- Кривая 1: S[1,1] из circuit-level модели (MCLIN) — из `Schematic 2`
- Кривая 2: S[1,1] из co-simulation (EM) — из `RS485_CoSim`

Они должны быть **близки**, но EM-модель покажет дополнительные эффекты (потери, краевые эффекты).

---

## Способ 3: EM Structure напрямую в основной схеме (замена MCLIN)

Если не хотите создавать новую схему:

### Шаг 1. В основной схеме удалите MCLIN

1. Откройте Schematic 2.
2. Выделите MCLIN (TL1) → **Delete**.
3. Также удалите **MSUB** (SUB1) и **EXTRACT** (EX1) — они больше не нужны.
4. STACKUP (SUB2) тоже можно удалить.

### Шаг 2. Вставьте EM Structure

1. Elements Browser → **Project → Subcircuits → RS485**.
2. Перетащите на место, где был MCLIN.
3. Подключите провода к выводам 1, 2, 3, 4 (там же, где были выводы MCLIN).

### Шаг 3. Запуск

F8 — схема теперь использует EM-модель вместо аналитической формулы MCLIN.

---

## Что даёт co-simulation по сравнению с чистым MCLIN

| Параметр | MCLIN (circuit) | EM Structure (AXIEM) |
|----------|-----------------|----------------------|
| Импеданс | По формулам (приближённо) | Из решения уравнений Максвелла (точно) |
| Потери | Приближённые | С учётом реальных Tand и σ |
| Краевые эффекты | Не учтены | Учтены |
| Связь между линиями | По формулам | Из EM-расчёта |
| Скорость расчёта | Мгновенно | Секунды (уже рассчитано) |
| E-field | Нет | Да (Analyst) / токи (AXIEM) |

## Какие результаты показать в отчёте

### График 1: Сравнение S[1,1] — MCLIN vs EM

Две кривые на одном графике:
- Circuit model (MCLIN): аналитическая модель
- EM model (AXIEM): электромагнитная модель

Вывод для отчёта:
> *Результаты circuit-level модели и EM-модели близки, что подтверждает корректность обеих моделей. EM-модель показывает несколько большие потери из-за учёта реальных свойств диэлектрика и эффектов краёв проводников.*

### График 2: S[1,1] из co-simulation

Отражение на входе с учётом всей нагрузки (терминатор + приёмник):
> *Коэффициент отражения < −10 дБ в диапазоне 1–100 МГц, что подтверждает согласование линии терминатором 120 Ом.*

### Распределение тока

Скриншот из EM Structure → Animate:
> *Ток сконцентрирован на внутренних краях проводников дифференциальной пары, что характерно для дифференциального режима передачи RS-485.*
