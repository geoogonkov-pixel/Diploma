# Моделирование линии RS-485 в AWR Design Environment 17

## Практическая инструкция

---

## 1. Описание минимально необходимой модели

### Что моделируется

Моделируется **передача дифференциального сигнала** по линии связи стандарта RS-485: от передатчика (драйвера) через кабель (витую пару) к приёмнику с учётом согласующих (терминирующих) резисторов.

### Принятые допущения

1. **Однопроводный эквивалент дифференциальной линии.** В RS-485 два провода несут равные и противоположные сигналы. В дифференциальном режиме их можно представить одной эквивалентной линией передачи с волновым сопротивлением, равным дифференциальному импедансу (120 Ом). Это стандартный и корректный подход в СВЧ-моделировании.
2. **Идеальная линия передачи** (без потерь или с малыми потерями). Для первого приближения потери в кабеле не учитываются — это даёт чистую картину отражений и согласования.
3. **Передатчик и приёмник** представлены портами с заданными импедансами, а не транзисторными моделями. Это достаточно для анализа линии передачи.
4. **Длина кабеля — 10 метров** (типичная для RS-485 в промышленных сетях). При частоте 5 МГц это примерно четверть длины волны — достаточно, чтобы наблюдать волновые эффекты.

### Почему именно такая модель

- Это **самая простая схема**, которая корректно описывает физику RS-485: передачу сигнала по линии с волновым сопротивлением и отражения при рассогласовании.
- Она использует **базовые элементы AWR** (порты, идеальную линию передачи) без дополнительных библиотек.
- Она позволяет наглядно показать **разницу между согласованной и несогласованной линией** — ключевой момент для RS-485.

### Роли элементов в модели

| Элемент | Роль в RS-485 |
|---------|---------------|
| PORT1 (порт 1) | Передатчик (драйвер RS-485) |
| TLIN (линия передачи) | Кабель витой пары (дифференциальный режим) |
| PORT2 (порт 2) | Приёмник + терминирующий резистор (нагрузка) |
| Земля (GND) | Общий (опорный) провод / экран кабеля |

## 2. Обязательные элементы схемы

### Полный список элементов минимальной рабочей модели

| № | Элемент AWR | Функция | Почему обязателен | Параметры |
|---|-------------|---------|-------------------|-----------|
| 1 | **PORT** (P1) | Источник сигнала / передатчик | Без источника нет сигнала для анализа. Порт задаёт импеданс источника и является точкой измерения S-параметров | Z = 120 Ом |
| 2 | **TLIN** | Идеальная линия передачи (кабель RS-485) | Это основной моделируемый объект — без него нечего анализировать | Z0 = 120 Ом, EL = 90°, F0 = 0.005 ГГц |
| 3 | **PORT** (P2) | Нагрузка / приёмник с терминатором | Без нагрузки невозможно измерить передачу сигнала (S21). Импеданс порта моделирует терминирующий резистор | Z = 120 Ом (согласованная), Z = 12000 Ом (несогласованная) |
| 4 | **GND** | Земля / опорный потенциал | Без земли схема не имеет общей точки, симуляция невозможна | — |

### Ответы на обязательные вопросы

| Вопрос | Ответ |
|--------|-------|
| Нужен ли источник сигнала? | **Да.** PORT1 — это источник. В S-параметрическом анализе порт одновременно является и источником, и точкой измерения |
| Нужна ли дифференциальная пара? | **Нет для минимальной модели.** Одна линия TLIN с Z0 = 120 Ом корректно представляет дифференциальный режим. Для расширенной модели можно использовать CLIN (связанные линии) |
| Нужны ли оконечные резисторы (терминаторы)? | **Да.** В минимальной модели их роль выполняет импеданс PORT2 (Z = 120 Ом). Для расширенной модели можно добавить явный элемент RES |
| Нужна ли нагрузка? | **Да.** PORT2 — это и терминатор, и нагрузка (приёмник) |
| Нужна ли земля? | **Да.** GND обязателен для замыкания цепи |
| Нужны ли модели линий передачи? | **Да.** TLIN — это и есть модель линии |
| Нужны ли порты? | **Да.** Минимум два порта для двухпортового анализа |
| Нужны ли графики/пробники? | **Да.** Без графиков невозможно увидеть результаты. Добавляются после создания схемы |

## 3. Пошаговая инструкция по созданию схемы

### Шаг 1. Создание нового проекта

1. Запустите AWR Design Environment 17 (NI AWR Design Environment / Cadence AWR Design Environment).
2. В главном меню выберите **File → New Project** (или нажмите **Ctrl+N**).
3. Появится пустое дерево проекта в левой панели (Project Browser).
4. Сохраните проект: **File → Save Project As...** → укажите имя, например `RS485_Model` → нажмите **Save**.

**Результат:** открыт пустой проект с деревом в левой панели.

### Шаг 2. Создание новой схемы

1. В дереве проекта (Project Browser, левая панель) найдите раздел **Circuit Schematics**.
2. Щёлкните правой кнопкой мыши по **Circuit Schematics**.
3. Выберите **New Schematic**.
4. В появившемся диалоге введите имя схемы: `RS485_Line`.
5. Нажмите **OK** (или **Create**).

**Результат:** откроется пустой лист схемы (Schematic Editor) с сеткой.

### Шаг 3. Добавление порта передатчика (PORT1)

1. В панели элементов (Elements Browser, обычно внизу слева) раскройте категорию **Circuit Elements → Ports**.
   - Альтернативный путь: меню **Draw → Add Element...** (или горячая клавиша — зависит от настроек), в поле поиска введите `PORT`.
2. Найдите элемент **PORT**.
3. Перетащите его на схему (или дважды щёлкните, затем кликните на схеме для размещения).
4. Разместите PORT в левой части схемы.
5. Дважды щёлкните по размещённому порту, чтобы открыть окно свойств (**Element Options**).
6. Установите параметры:
   - **Port Number (PRT):** `1` (обычно присваивается автоматически)
   - **Z (Impedance):** `120` Ом
   - **Pwr:** оставьте по умолчанию (0 dBm)
7. Нажмите **OK**.

**Зачем:** PORT1 моделирует передатчик RS-485. Импеданс 120 Ом выбран для согласования с линией (случай идеального согласования). Позже мы изменим его для моделирования реального драйвера.

**Результат:** на схеме появился порт P1 с обозначением «PORT Z=120 Ohm».

### Шаг 4. Добавление идеальной линии передачи (TLIN)

1. В панели элементов раскройте категорию **Circuit Elements → Transmission Lines → Ideal**.
   - Альтернативный путь: **Draw → Add Element...**, в поле поиска введите `TLIN`.
2. Найдите элемент **TLIN** (Ideal Transmission Line).
3. Перетащите его на схему, разместите справа от PORT1.
4. Дважды щёлкните по элементу TLIN для открытия свойств.
5. Установите параметры:
   - **Z0 (Characteristic Impedance):** `120` Ом
   - **EL (Electrical Length):** `90` градусов
   - **F0 (Reference Frequency):** `0.005` ГГц (= 5 МГц)
6. Нажмите **OK**.

**Зачем:** TLIN — это модель кабеля RS-485. Параметры означают:
- Z0 = 120 Ом — стандартное дифференциальное волновое сопротивление кабеля RS-485.
- EL = 90° при F0 = 5 МГц — это эквивалент кабеля длиной ~10 метров (четверть длины волны при 5 МГц, с учётом скорости распространения в кабеле).
- При других частотах электрическая длина масштабируется автоматически: при 10 МГц она будет 180°, при 50 МГц — 900° и т.д.

**Результат:** на схеме появился элемент линии передачи с двумя сигнальными выводами и выводом земли.

### Шаг 5. Добавление порта приёмника (PORT2) — согласованная нагрузка

1. Добавьте ещё один элемент **PORT** (аналогично шагу 3).
2. Разместите его справа от TLIN.
3. Дважды щёлкните по нему и установите параметры:
   - **Port Number (PRT):** `2`
   - **Z (Impedance):** `120` Ом
4. Нажмите **OK**.

**Зачем:** PORT2 моделирует приёмник RS-485 с подключённым терминирующим резистором 120 Ом. В первом варианте модели приёмник и терминатор объединены в один элемент.

**Результат:** на схеме размещены PORT1, TLIN и PORT2 в ряд.

### Шаг 6. Добавление земли (GND)

1. В панели элементов найдите элемент **GND** (Ground).
   - Путь: **Circuit Elements → Ports** или используйте поиск `GND`.
   - Часто GND доступен через панель инструментов (значок «земля»).
2. Разместите элементы GND:
   - Один GND — под нижним выводом TLIN (вывод земли линии).
   - Один GND — под PORT1 (если порт имеет отдельный вывод земли).
   - Один GND — под PORT2.

**Примечание:** В AWR DE элемент PORT обычно уже содержит встроенную землю (один вывод — сигнальный, второй — земля). Однако TLIN может иметь отдельный вывод земли, который нужно подключить. Если у PORT вывод земли автоматический — дополнительный GND не нужен, но у TLIN нижние выводы необходимо соединить с GND.

**Результат:** все элементы имеют корректное подключение к земле.

### Шаг 7. Соединение элементов проводами

1. Выберите инструмент рисования проводов: **Draw → Wire** (или нажмите горячую клавишу, обычно **W** или **Ctrl+W**).
2. Соедините:
   - **Сигнальный выход PORT1** → **левый вход TLIN** (верхний левый вывод линии).
   - **Правый выход TLIN** (верхний правый вывод) → **сигнальный вход PORT2**.
   - **Нижние выводы TLIN** (земляные) → **GND**.
3. Для завершения провода — двойной щелчок или нажмите **Escape**.
4. Убедитесь, что на соединениях появились точки (nodes) — это означает электрический контакт.

**Результат:** схема представляет собой цепочку PORT1 → TLIN → PORT2 с общей землёй. Это двухпортовая цепь.

### Шаг 8. Проверка схемы

1. Визуально убедитесь, что:
   - PORT1 подключён к левому входу TLIN.
   - Правый выход TLIN подключён к PORT2.
   - Земляные выводы подключены к GND.
   - Нет «висящих» (неподключённых) выводов — они обычно обозначаются красным кружком или крестиком.
2. Если есть неподключённые выводы — дотяните провода до ближайшего узла или GND.

**Результат:** схема готова к настройке симуляции. Она должна выглядеть как три элемента в линию: [PORT1]—[TLIN]—[PORT2].

### Шаг 9. Настройка частотного диапазона

1. В дереве проекта найдите раздел **Project Options** (или **Frequencies**).
   - Альтернативный путь: щёлкните правой кнопкой мыши по имени проекта в дереве → **Options...** → вкладка **Frequencies**.
   - Или: меню **Simulate → Frequency...** или **Project → Project Options → Frequencies**.
2. Установите частотный диапазон:
   - **Start:** `0.001` ГГц (= 1 МГц)
   - **Stop:** `0.1` ГГц (= 100 МГц)
   - **Step:** `0.001` ГГц (= 1 МГц)
3. Нажмите **Apply** → **OK**.

**Зачем:** RS-485 работает на частотах до 10 МГц (максимальная скорость передачи — 10 Мбит/с). Диапазон 1–100 МГц охватывает основную полосу частот и несколько гармоник, что позволяет увидеть поведение линии на высоких частотах.

**Результат:** проект настроен на линейный анализ (S-параметры) в диапазоне 1–100 МГц с шагом 1 МГц (100 частотных точек).

## 4. Инструкция по моделированию

### 4.1. Тип анализа

В AWR DE 17 используется **линейный частотный анализ (Linear / S-Parameter Analysis)** — это анализ по умолчанию для схем с портами.

**Почему именно этот анализ:**
- Это «родной» тип анализа AWR — он работает надёжно и не требует дополнительных настроек.
- S-параметры полностью описывают поведение линии передачи: коэффициент отражения (S11), коэффициент передачи (S21), потери, набег фазы.
- Из S-параметров можно получить временну́ю характеристику (TDR) через обратное преобразование Фурье.
- Анализ подходит для задач целостности сигналов (Signal Integrity), что и представляет RS-485.

### 4.2. Создание графиков

#### График 1: Коэффициент отражения S11 (Return Loss)

1. В дереве проекта щёлкните правой кнопкой мыши по разделу **Graphs**.
2. Выберите **New Graph**.
3. В диалоге:
   - **Graph Name:** `S11_Return_Loss`
   - **Graph Type:** `Rectangular` (прямоугольный график)
4. Нажмите **OK** — откроется пустой график.
5. Щёлкните правой кнопкой мыши внутри графика → **Add Measurement** (или **Add New Measurement**).
6. В диалоге добавления измерения:
   - **Measurement Type (Категория):** `Port Parameters` → `S`
   - **Measurement:** `S[1,1]` (или выберите S, затем порт 1 → порт 1)
   - **Data Source:** `RS485_Line` (имя вашей схемы)
   - **Complex Modifier (Формат):** `DB` (децибелы, т.е. 20·log₁₀|S11|)
7. Нажмите **OK**.

**Результат:** на графике появится кривая S11 в дБ после запуска симуляции.

#### График 2: Коэффициент передачи S21 (Insertion Loss)

1. Аналогично создайте новый график **Rectangular** с именем `S21_Insertion_Loss`.
2. Добавьте измерение:
   - **Measurement:** `S[2,1]`
   - **Complex Modifier:** `DB`

**Результат:** график покажет, сколько сигнала доходит от передатчика к приёмнику.

#### График 3: КСВН (VSWR) — опционально

1. Создайте график `VSWR`.
2. Добавьте измерение:
   - **Measurement Type:** `Port Parameters` → `VSWR`
   - **Measurement:** `VSWR[1]` (или VSWR для порта 1)

**Результат:** график КСВН покажет качество согласования со стороны передатчика.

#### График 4: Групповая задержка (Group Delay) — опционально

1. Создайте график `Group_Delay`.
2. Добавьте измерение:
   - **Measurement:** `S[2,1]`
   - **Complex Modifier:** `GD` (Group Delay) или `GrpDly`

**Результат:** покажет время задержки сигнала в линии.

#### График 5: Фаза S21 — опционально

1. Создайте график `S21_Phase`.
2. Добавьте измерение:
   - **Measurement:** `S[2,1]`
   - **Complex Modifier:** `Ang` (угол в градусах)

### 4.3. Запуск симуляции

1. Нажмите **Simulate → Analyze** (или горячую клавишу **F8**, или кнопку **Analyze** на панели инструментов — обычно зелёная стрелка ▶).
2. В строке состояния (внизу окна) появится индикатор прогресса.
3. Для простой модели расчёт выполняется мгновенно (менее 1 секунды).

**Результат:** на всех созданных графиках появятся кривые.

### 4.4. Что должно получиться (согласованная линия, Z_PORT2 = 120 Ом)

- **S11 (дБ):** должен быть **очень низким** по всему диапазону частот, значительно ниже −20 дБ (идеально: −∞ дБ, т.е. нет отражений). На практике для идеальной линии AWR покажет значения ниже −40 дБ или отсутствие отражений.
  - **Это означает:** линия идеально согласована, отражений нет.
- **S21 (дБ):** должен быть **~0 дБ** по всему диапазону частот (для линии без потерь).
  - **Это означает:** весь сигнал передаётся от входа к выходу без потерь.
- **КСВН:** близок к 1.0.
- **Групповая задержка:** постоянна на всех частотах (~33 нс для 10 м кабеля).

### 4.5. Моделирование несогласованной линии (без терминатора)

Чтобы увидеть разницу и понять важность терминирующего резистора:

1. Дважды щёлкните по **PORT2** на схеме.
2. Измените **Z (Impedance)** с `120` на `12000` Ом (имитация приёмника RS-485 без терминатора — входное сопротивление приёмника ≥ 12 кОм).
3. Нажмите **OK**.
4. Запустите симуляцию: **Simulate → Analyze** (F8).

**Что изменится:**
- **S11 (дБ):** станет значительно выше (ближе к 0 дБ), с периодическими пиками и провалами. Это **стоячие волны** — сигнал отражается от несогласованной нагрузки и интерферирует сам с собой.
  - Пики S11 ≈ 0 дБ означают почти полное отражение.
  - Периодичность пиков определяется длиной линии.
- **S21 (дБ):** перестанет быть ровным — появятся осцилляции.
- **КСВН:** станет значительно больше 1 (порядка 100:1).

**Это наглядно демонстрирует:** без терминирующего резистора 120 Ом линия RS-485 работает некорректно — возникают отражения, искажающие сигнал.

## 5. Получение и интерпретация результатов

### 5.1. Обязательные результаты для минимальной модели

| Результат | Что показывает | Где смотреть в AWR |
|-----------|---------------|---------------------|
| S11 (дБ) vs частота | Коэффициент отражения от входа линии | График S11_Return_Loss |
| S21 (дБ) vs частота | Коэффициент передачи (прохождение сигнала) | График S21_Insertion_Loss |
| VSWR vs частота | Коэффициент стоячей волны (качество согласования) | График VSWR |

### 5.2. Как увидеть прохождение сигнала по линии

- **S21 (дБ):** значение около 0 дБ означает, что сигнал проходит полностью. Значение −3 дБ означает потерю половины мощности. Значение −10 дБ — потерю 90% мощности.
- **Фаза S21:** линейно нарастает с частотой — это задержка в линии. Чем длиннее линия, тем быстрее растёт фаза.
- **Групповая задержка:** постоянное значение означает неискажённую передачу. Для кабеля 10 м: τ = L × √Eeff / c = 10 × 1.517 / 3×10⁸ ≈ 50.6 нс.

### 5.3. Как проверить влияние терминаторов

Сравните два случая:

| Параметр | Согласованная линия (Z₂ = 120 Ом) | Несогласованная линия (Z₂ = 12000 Ом) |
|----------|--------------------------------------|------------------------------------------|
| S11 (дБ) | < −40 дБ (ровная линия) | Периодические пики от 0 до −20 дБ |
| S21 (дБ) | ≈ 0 дБ (ровная линия) | Периодические осцилляции |
| КСВН | ≈ 1.0 | > 10 (сильные стоячие волны) |

Этот контраст наглядно доказывает необходимость терминирующего резистора 120 Ом.

### 5.4. Признаки корректной модели

- Для согласованной линии S11 < −30 дБ на всех частотах.
- S21 ≈ 0 дБ (для идеальной линии без потерь — точно 0 дБ).
- Групповая задержка — константа.
- При изменении Z_PORT2 с 120 на 12000 Ом — появляется явная периодическая структура в S11.

### 5.5. Признаки неправильно собранной модели

- S11 = 0 дБ на всех частотах → вероятно, оборван провод или порт не подключён.
- S21 = −∞ дБ → сигнал не проходит, скорее всего разрыв в цепи.
- S21 > 0 дБ → активное усиление, невозможно для пассивной цепи — ошибка в модели.
- S11 и S21 не зависят от частоты при несогласованной нагрузке → вероятно, TLIN имеет нулевую длину (EL = 0).
- Ошибка симуляции «Floating node» → какой-то вывод элемента не подключён к цепи.

### 5.6. Какие графики обязательно сохранить

Для учебной работы необходимы минимум **четыре графика**:

1. **S11 (дБ), согласованная линия** — показывает отсутствие отражений.
2. **S11 (дБ), несогласованная линия** — показывает сильные отражения.
3. **S21 (дБ), согласованная линия** — показывает полную передачу сигнала.
4. **S21 (дБ), несогласованная линия** — показывает искажения передачи.

Для сохранения: щёлкните правой кнопкой мыши по графику → **Export...** или **Copy to Clipboard** → вставьте в отчёт. Также можно использовать **File → Export → Output...** для экспорта в PDF или изображение.

### 5.7. Краткая интерпретация для учебной работы

> При согласованной нагрузке (терминирующий резистор 120 Ом) коэффициент отражения S11 пренебрежимо мал, а коэффициент передачи S21 близок к 0 дБ на всех частотах до 100 МГц. Это означает, что сигнал передаётся по линии без отражений и потерь.
>
> При отсутствии терминирующего резистора (нагрузка 12 кОм — только входной импеданс приёмника) коэффициент отражения резко возрастает, а коэффициент передачи приобретает периодическую частотную зависимость. Стоячие волны в линии искажают передаваемый сигнал, что может привести к ошибкам при приёме данных.
>
> Результаты моделирования подтверждают, что для корректной работы интерфейса RS-485 необходимо согласование линии терминирующим резистором, равным волновому сопротивлению кабеля (120 Ом).

## 7. Реализация топологии / печатной платы

### 7.1. Возможности AWR DE 17

AWR Design Environment 17 **не является полноценным САПР для проектирования печатных плат** (как Altium Designer, KiCad или OrCAD). AWR — это инструмент для проектирования СВЧ-схем и электромагнитного моделирования.

Однако AWR DE 17 **позволяет:**
- Создавать **топологию микрополосковых и полосковых линий** (Layout Editor).
- Выполнять **электромагнитное моделирование** этих линий (AXIEM — планарный 3D EM-солвер, или Analyst — полный 3D EM-солвер).
- Моделировать **связанные микрополосковые линии** (дифференциальные пары) на печатной плате.

### 7.2. Что можно реально сделать для учебной работы

Наиболее реалистичный вариант: **моделирование участка дифференциальной пары RS-485 на печатной плате** с использованием связанных микрополосковых линий (MCLIN).

Это не полноценная разводка платы, но демонстрирует:
- Как рассчитать ширину дорожек и зазор для дифференциального импеданса 120 Ом.
- Как влияет геометрия дорожек на импеданс линии.
- Как выглядит топология дифференциальной пары в AWR.

### 7.3. Пошаговая инструкция: модель дифференциальной пары на плате

#### Шаг 1. Определение подложки (Substrate)

1. Создайте новую схему: правой кнопкой по **Circuit Schematics** → **New Schematic** → имя: `RS485_PCB`.
2. Добавьте элемент подложки: **Circuit Elements → Substrates → MSUB** (Microstrip Substrate).
3. Перетащите MSUB на схему.
4. Дважды щёлкните по MSUB и задайте параметры (типичная плата FR-4):
   - **Er (диэлектрическая проницаемость):** `4.6` (FR-4)
   - **H (толщина диэлектрика):** `1.5` мм (стандарт для двухслойной платы; если единица — mil, то `59` mil)
   - **T (толщина меди):** `0.035` мм (35 мкм, стандарт 1 oz/ft²; или `1.38` mil)
   - **Rho (удельное сопротивление):** `1` (нормировано к меди)
   - **Tand (тангенс угла потерь):** `0.02` (типично для FR-4)
   - **ErNom:** `4.6` (номинальная Er)
   - **Name:** `FR4` (или оставьте по умолчанию)
5. Нажмите **OK**.

#### Шаг 2. Добавление связанных микрополосковых линий (MCLIN)

1. Добавьте элемент: **Circuit Elements → Transmission Lines → Coupled Lines → MCLIN** (Coupled Microstrip Lines).
2. Разместите на схеме.
3. Дважды щёлкните и задайте параметры:
   - **W (ширина дорожки):** `0.3` мм (начальное значение; будет уточнено)
   - **S (зазор между дорожками):** `0.2` мм
   - **L (длина дорожки):** `50` мм (участок дифференциальной пары длиной 5 см)
   - **MSUB:** выберите подложку `FR4` (из списка)
4. Нажмите **OK**.

**Примечание:** для получения дифференциального импеданса 120 Ом на FR-4 с H = 1.5 мм, типичные значения ширины W ≈ 0.2–0.5 мм и зазора S ≈ 0.15–0.3 мм. Точные значения зависят от конкретных параметров подложки. Можно использовать встроенный калькулятор AWR (**Tools → TXLine...**) для расчёта.

#### Шаг 3. Использование калькулятора TXLine

1. В главном меню: **Tools → TXLine...** (или **TX-Line Calculator**).
2. Выберите тип линии: **Coupled Microstrip**.
3. Задайте параметры подложки: Er = 4.6, H = 1.5 мм, T = 0.035 мм.
4. Задайте целевой дифференциальный импеданс: Zdiff = 120 Ом.
5. Нажмите **Synthesize** (синтезировать) — калькулятор рассчитает необходимые W и S.
6. Запишите полученные значения и внесите их в параметры MCLIN.

#### Шаг 4. Сборка схемы с MCLIN

Соберите схему аналогично основной модели, но вместо TLIN используйте MCLIN:

```
PORT1 (Z=60 Ом) ──── MCLIN (линия 1, верхние выводы) ──── PORT3 (Z=60 Ом)
PORT2 (Z=60 Ом) ──── MCLIN (линия 2, нижние выводы) ──── PORT4 (Z=60 Ом)
```

**Важно:** MCLIN — это 4-портовый элемент (четыре сигнальных вывода). Для дифференциального анализа:
- Порты 1 и 2 — вход дифференциальной пары (подключить к PORT1 и PORT2).
- Порты 3 и 4 — выход дифференциальной пары (подключить к PORT3 и PORT4).
- Каждый порт имеет импеданс Z = 60 Ом (половина дифференциального импеданса).

#### Шаг 5. Просмотр топологии (Layout)

1. Откройте схему `RS485_PCB`.
2. В меню: **View → Layout** (или **Window → Layout**; или нажмите на вкладку **Layout** внизу редактора схемы).
3. AWR автоматически сгенерирует топологию на основе элементов схемы.
4. Вы увидите **две параллельные дорожки** (дифференциальная пара) с заданными шириной W и зазором S.

**Результат:** визуальное представление участка дифференциальной пары RS-485 на печатной плате.

#### Шаг 6. EM-симуляция топологии (опционально)

Для электромагнитного моделирования топологии:
1. В дереве проекта: правой кнопкой по **EM Structures** → **New EM Structure**.
2. Импортируйте топологию из Layout или создайте вручную.
3. Задайте подложку и слои (Stackup).
4. Задайте порты на входе и выходе дорожек.
5. Запустите AXIEM-симуляцию: **Simulate → Analyze**.

**Это продвинутая тема** и для минимальной учебной работы не обязательна.

### 7.4. Ограничения и рекомендации

- AWR DE **не генерирует Gerber-файлы** для изготовления плат (в отличие от Altium или KiCad).
- AWR DE **не имеет библиотеки стандартных компонентов** (микросхем RS-485, разъёмов и т.д.).
- Для полноценного проекта печатной платы RS-485 используйте **специализированный САПР** (Altium Designer, KiCad, OrCAD), а из AWR экспортируйте **рассчитанные параметры дорожек** (ширина, зазор, импеданс).
- Для учебной работы **достаточно** показать топологию дифференциальной пары в AWR Layout и результаты S-параметрического анализа модели с MCLIN.

## 8. Расширенная модель: явные элементы драйвера и приёмника

Для более наглядного представления RS-485 можно собрать расширенную модель с явными резисторами.

### Схема расширенной модели

```
                    Кабель RS-485
PORT1 ─── RES(10) ─── TLIN(Z0=120) ─── NODE_B ─── PORT2
(источник) (Rdrv)      (линия 10 м)      │
                                        RES(120) ← терминатор
                                          │
                                         GND
```

### Элементы и их параметры

| Элемент | Параметр | Значение | Назначение |
|---------|----------|----------|------------|
| PORT1 | Z | 1 Ом (или 50 Ом) | Источник сигнала (низкоомный) |
| RES (R_drv) | R | 10 Ом | Выходное сопротивление драйвера RS-485 |
| TLIN | Z0 | 120 Ом | Кабель витой пары |
| TLIN | EL | 90° | Электрическая длина (~10 м) |
| TLIN | F0 | 0.005 ГГц | Опорная частота |
| RES (R_term) | R | 120 Ом | Терминирующий резистор |
| PORT2 | Z | 12000 Ом | Приёмник RS-485 (высокий входной импеданс) |
| GND | — | — | Общий провод |

### Как собрать

1. Добавьте **RES** (Circuit Elements → Lumped Elements → RES).
2. Разместите его между PORT1 и TLIN.
3. Задайте R = 10 Ом (двойной щелчок → Properties → R = 10).
4. Добавьте второй **RES** (R_term, R = 120 Ом).
5. Подключите его между выходом TLIN (node_B) и GND.
6. PORT2 (Z = 12000 Ом) подключите к тому же узлу node_B.
7. Соедините все элементы проводами.

### Что покажет эта модель

- Влияние выходного сопротивления драйвера на согласование.
- Работу терминирующего резистора как отдельного элемента.
- Передачу сигнала в реальных условиях (источник не согласован с линией, но линия согласована нагрузкой).

## 9. Расширенная модель: связанные линии (CLIN) для дифференциальной пары

Если требуется показать обе линии RS-485 (дифференциальную пару):

### Элемент CLIN

- **Путь:** Circuit Elements → Transmission Lines → Coupled Lines → **CLIN** (Coupled Ideal Transmission Lines).
- Параметры:
  - **ZE (Z0E, Even-mode impedance):** `80` Ом — импеданс чётной моды
  - **ZO (Z0O, Odd-mode impedance):** `60` Ом — импеданс нечётной моды
  - **EL:** `90` градусов
  - **F0:** `0.005` ГГц

**Связь с дифференциальным импедансом:**
- Zdiff = 2 × Z0O = 2 × 60 = **120 Ом** ✓
- Zcomm = Z0E / 2 = 80 / 2 = **40 Ом**

### Схема с CLIN (4-портовая)

```
PORT1 (+) ──── CLIN (вывод 1 → вывод 3) ──── PORT3 (+)
PORT2 (−) ──── CLIN (вывод 2 → вывод 4) ──── PORT4 (−)
```

- PORT1, PORT2 — дифференциальный вход (драйвер).
- PORT3, PORT4 — дифференциальный выход (приёмник).
- Каждый порт Z = 60 Ом (половина дифференциального импеданса).
- RES 120 Ом между PORT3 и PORT4 — терминатор.

Эта модель позволяет анализировать не только дифференциальный, но и синфазный режимы.

## Приложение А. Справочные формулы

| Параметр | Формула | Пример |
|----------|---------|--------|
| Электрическая длина (°) | EL = 360 × L × f₀ × √Eeff / c | EL = 360 × 10 × 5×10⁶ × 1.52 / 3×10⁸ ≈ 91° |
| Физическая длина (м) | L = EL × c / (360 × f₀ × √Eeff) | L = 90 × 3×10⁸ / (360 × 5×10⁶ × 1.52) ≈ 9.87 м |
| Коэффициент отражения | Γ = (Z_L − Z₀) / (Z_L + Z₀) | Γ = (12000 − 120) / (12000 + 120) ≈ 0.98 |
| Задержка в линии (с) | τ = L × √Eeff / c | τ = 10 × 1.52 / 3×10⁸ ≈ 50.6 нс |
| Дифф. импеданс (CLIN) | Zdiff = 2 × Z0O | Zdiff = 2 × 60 = 120 Ом |

**Обозначения:**
- L — физическая длина кабеля (м)
- f₀ — опорная частота (Гц)
- Eeff — эффективная диэлектрическая проницаемость (для витой пары в полиэтилене ≈ 2.3)
- c — скорость света (3×10⁸ м/с)
- Z_L — импеданс нагрузки
- Z₀ — волновое сопротивление линии
