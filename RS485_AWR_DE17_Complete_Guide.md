## 1. Проверка применимости AWR DE 17

### 1.1. Три уровня задачи

Задача «смоделировать RS-485 и получить распределение электрического поля» на самом деле состоит из трёх принципиально разных подзадач:

| Подзадача | Что делаем | Какой инструмент AWR |
|-----------|-----------|---------------------|
| **Circuit-level модель** | Моделируем схему RS-485: драйвер, линию передачи, приёмник, терминатор. Получаем S-параметры, проверяем согласование | **Microwave Office** (Schematic Editor) |
| **EM-модель линии** | Моделируем физическую геометрию дифференциальной пары (проводники, подложка, земля). Получаем точные S-параметры с учётом реальной физики | **AXIEM** (2.5D MoM) или **Analyst** (3D FEM) |
| **Распределение E-field** | Визуализируем электрическое поле в пространстве вокруг проводников | **Analyst** (обязательно для полной визуализации E-field) |

### 1.2. Какие модули AWR нужны обязательно

| Модуль | Для чего нужен | Обязательность |
|--------|---------------|----------------|
| **Microwave Office** (базовый) | Circuit Schematic — создание схемной модели RS-485 с элементами CLIN, RES, CAP, PORT. Расчёт S-параметров. Калькулятор TXLine | **Обязателен** — это ядро AWR DE 17, без него ничего не работает |
| **AXIEM** | EM Structure — 2.5D планарный солвер (Method of Moments). Расчёт S-параметров из реальной геометрии проводников. Визуализация токов на поверхности | **Обязателен для EM-модели.** Обычно входит в базовую лицензию AWR DE 17 |
| **Analyst** | EM Structure — полный 3D FEM-солвер. Расчёт S-параметров + **полная визуализация E-field, H-field, J в пространстве** | **Обязателен для визуализации E-field.** Может требовать дополнительную лицензию |

### 1.3. Что можно сделать в Microwave Office (без AXIEM/Analyst)

- Построить полную circuit-level модель RS-485 (драйвер + линия + приёмник).
- Рассчитать S-параметры, return loss, insertion loss.
- Проверить согласование, наблюдать стоячие волны.
- Провести mixed-mode анализ (Sdd, Scc, Sdc, Scd).
- Рассчитать геометрию дорожек через TXLine.
- **Нельзя:** получить распределение электрического поля, визуализировать поле в пространстве, учесть реальные эффекты краёв проводников, паразитные связи из-за геометрии.

### 1.4. Что нужно делать в AXIEM

- Создание EM Structure с реальной геометрией проводников.
- Расчёт S-параметров с учётом реальной физики (потери в диэлектрике, эффект краёв, неоднородности).
- Визуализация **плотности тока на поверхности** проводников (Current Density).
- S-параметры из AXIEM можно использовать в co-simulation со схемной моделью.
- **Нельзя:** визуализировать электрическое поле E в объёме (в пространстве между проводниками и вокруг них). AXIEM — планарный 2.5D-солвер, он не рассчитывает поля вне плоскости проводников.

### 1.5. Когда нужен Analyst вместо AXIEM

**Analyst (3D FEM) нужен обязательно, если требуется:**

- Визуализация распределения E-field в поперечном сечении между проводниками, в подложке, над платой.
- Визуализация H-field и векторных карт полей.
- Моделирование трёхмерных структур (переходные отверстия, разъёмы, неоднородности).
- Любой результат, требующий **полного 3D-решения уравнений Максвелла** в объёме.

**Analyst предпочтительнее AXIEM, когда:**

| Критерий | AXIEM | Analyst |
|----------|-------|---------|
| Тип структуры | Планарная (микрополоски, копланарные линии) | Любая 3D-геометрия |
| Визуализация полей | Только токи на поверхности | E, H, J в полном объёме |
| Скорость | Быстрее (секунды) | Медленнее (минуты) |
| Точность для планарных структур | Высокая | Высокая |
| Переходные отверстия, 3D-элементы | Ограниченно | Полная поддержка |

**Для нашей задачи (E-field distribution) выбор однозначный: Analyst.** Если Analyst недоступен по лицензии — AXIEM даст S-параметры и токи, а распределение E-field придётся интерпретировать аналитически (подробности в Приложении А).

### 1.6. Что в AWR DE 17 сделать нельзя или неудобно

| Задача | Возможность в AWR DE 17 |
|--------|------------------------|
| Моделирование витой пары как 3D-спирали | **Нельзя.** AWR не поддерживает спиральную 3D-геометрию кабеля. Витая пара моделируется абстрактно через элемент CLIN (связанные линии передачи) |
| Скалярное поле потенциала φ(x,y,z) | **Нет прямого вывода.** AWR не выводит потенциал как отдельную величину. Но E = −∇φ, поэтому карта E-field эквивалентна карте градиента потенциала (подробнее — раздел 5) |
| Полноценный PCB-дизайн | **Очень ограниченно.** AWR — не САПР печатных плат. Нет генерации Gerber, нет библиотеки компонентов, нет DRC/DFM. Подробнее — раздел 9 |
| Моделирование протокола RS-485 | **Нельзя и не нужно.** AWR моделирует физику (поля, импедансы, S-параметры), а не логику передачи данных. Протокольный уровень — это задача для SPICE или HDL-симуляторов |
| Time-domain анализ (осциллограмма) | **Ограниченно.** AWR Microwave Office в первую очередь — frequency-domain инструмент. Для полноценного time-domain анализа (eye diagram, jitter) используются другие инструменты |

### 1.7. Ключевое ограничение: RS-485 — это интерфейс, а не геометрия

RS-485 — стандарт *передачи данных* (EIA/TIA-485). Он определяет электрические характеристики (уровни напряжения, импедансы, скорость), но **не определяет геометрию проводников**.

В реальной системе RS-485 сигнал проходит путь:

```
Микросхема-драйвер → [дорожки на плате TX] → разъём → [кабель витой пары] → разъём → [дорожки на плате RX] → микросхема-приёмник
```

AWR может моделировать:
- **Дорожки на плате** — через EM Structure (AXIEM/Analyst) с реальной геометрией. Здесь и получается E-field.
- **Кабель витой пары** — через элемент CLIN (абстрактные связанные линии). Здесь E-field получить нельзя.
- **Драйвер и приёмник** — через эквивалентные схемы (резисторы, ёмкости, порты).

**Вывод:** для получения E-field мы моделируем конкретный физический участок — дифференциальную пару на печатной плате (coupled microstrip). Это реальная часть системы RS-485, и AWR полностью поддерживает её EM-анализ.

## 2. Минимально работоспособная модель RS-485

### 2.1. Стратегия: от простого к сложному

Модель строится **в три этапа**. Каждый этап добавляет реалистичности, но начинать нужно с простейшего, чтобы убедиться в базовой работоспособности.

| Этап | Название | Что моделируется | Уровень |
|------|----------|------------------|---------|
| **A** | Базовая circuit-level модель | CLIN + 4 порта (все Z=60 Ом) | Schematic (Microwave Office) |
| **B** | EM-модель дифференциальной пары | Реальная геометрия проводников на FR-4 | EM Structure (AXIEM/Analyst) |
| **C** | Визуализация E-field | Распределение электрического поля | Analyst Field Viewer |

### 2.2. Обязательные элементы модели и зачем каждый из них нужен

#### Для circuit-level модели (этап A)

| № | Элемент AWR | Параметры | Назначение | Почему обязателен |
|---|------------|-----------|------------|-------------------|
| 1 | **PORT (P1)** | PRT=1, Z=60 Ом | Вход линии A (эквивалент выхода драйвера +) | Определяет возбуждение и импеданс со стороны источника. Z=60 Ом — это Z0O (импеданс нечётной моды), обеспечивающий согласование с CLIN |
| 2 | **PORT (P2)** | PRT=2, Z=60 Ом | Вход линии B (эквивалент выхода драйвера −) | Второй проводник дифференциальной пары. Z=60 Ом для согласования |
| 3 | **CLIN** | Z0E=90, Z0O=60, EL=60°, F0=0.005 ГГц | Витая пара / дифференциальная линия передачи | Единственный элемент, моделирующий физику RS-485: два электромагнитно связанных проводника с дифференциальным импедансом Zdiff = 2×Z0O = 120 Ом |
| 4 | **PORT (P3)** | PRT=3, Z=60 Ом | Выход линии A (эквивалент входа приёмника + и терминатора) | Z=60 Ом обеспечивает согласованную нагрузку. Дифференциальный импеданс PORT3+PORT4 = 2×60 = 120 Ом — эквивалент терминирующего резистора |
| 5 | **PORT (P4)** | PRT=4, Z=60 Ом | Выход линии B (эквивалент входа приёмника − и терминатора) | Замыкает дифференциальную пару на выходе |
| 6 | **GND** (×2) | — | Заземление CLIN | CLIN имеет два земляных вывода. Без их заземления получается ошибка «Floating node» |

**Вычисляемые характеристики базовой модели:**
- Zdiff = 2 × Z0O = 2 × 60 = **120 Ом** (стандарт RS-485)
- Zcomm = Z0E / 2 = 90 / 2 = **45 Ом** (синфазный импеданс)
- Коэффициент связи k = (Z0E − Z0O) / (Z0E + Z0O) = 30/150 = **0.2**
- Задержка: τ = EL / (360 × F0) = 60 / (360 × 5 МГц) = **33.3 нс**
- Физическая длина ≈ EL × c / (360 × F0 × √εeff) ≈ **6.6 м** (при εeff ≈ 2.3 для витой пары)

#### Для EM-модели (этап B)

| № | Элемент | Параметры | Назначение | Почему обязателен |
|---|---------|-----------|------------|-------------------|
| 1 | **Подложка (Substrate/Stackup)** | Er=4.6, H=1.5 мм, Tand=0.02 | Среда распространения поля между проводниками и землёй | Без подложки нет микрополосковой структуры. Er определяет скорость распространения и импеданс. Tand определяет потери |
| 2 | **Земляная плоскость (Ground Plane)** | PEC или Cu, T=0.035 мм | Опорный потенциал φ=0, обратный ток | Без неё это не microstrip, а двухпроводная линия в воздухе. Земля задаёт граничное условие и определяет характеристический импеданс |
| 3 | **Проводник A** | W=0.3 мм, L=30 мм, T=0.035 мм, Cu | Один из двух проводников дифференциальной пары | Физическая дорожка, по которой протекает ток и вокруг которой формируется поле |
| 4 | **Проводник B** | W=0.3 мм, L=30 мм, T=0.035 мм, Cu, зазор S=0.2 мм | Второй проводник | Вместе с проводником A образует связанную дифференциальную пару. Зазор S определяет степень связи |
| 5 | **Edge Port 1** | На входном торце проводника A | Источник возбуждения и точка измерения S-параметров | Без портов нечего возбуждать и нечего измерять |
| 6 | **Edge Port 2** | На входном торце проводника B | Второй вход дифференциальной пары | Для дифференциального возбуждения нужны два порта на входе |
| 7 | **Edge Port 3** | На выходном торце проводника A | Выходной порт, нагрузка | Определяет условие на дальнем конце линии |
| 8 | **Edge Port 4** | На выходном торце проводника B | Выходной порт | Замыкает дифференциальную пару |
| 9 | **Enclosure (границы)** | 5×32×5 мм, Approximate Open | Определяет расчётную область и граничные условия | Без границ солвер не знает, где заканчивается модель. Open-условия имитируют бесконечное пространство |
| 10 | **Настройки mesh** | Normal или Fine | Дискретизация геометрии для расчёта | Слишком грубая сетка даёт артефакты в полях. Слишком мелкая — долгий расчёт без выигрыша |

#### Дополнительные элементы (для расширенной модели)

| Элемент | Когда нужен | Параметры |
|---------|-------------|-----------|
| **Согласующий резистор 120 Ом** | Когда моделируем терминатор явно (а не через импеданс портов) | RES, R=120 Ом, между Pin3 и Pin4 CLIN |
| **R_drv (выходное сопротивление драйвера)** | Для реалистичной модели передатчика | RES, R=50 Ом, последовательно с каждой линией на входе |
| **R_rcv (входное сопротивление приёмника)** | Для полной модели приёмника | RES, R=12 кОм, от каждой линии к земле |
| **C_rcv (входная ёмкость приёмника)** | Для учёта паразитных параметров приёмника | CAP, C=15 пФ, параллельно R_rcv |
| **Переходные отверстия (vias)** | Если моделируется переход между слоями платы | В EM Structure: via cylinder, D=0.3 мм, drill=0.2 мм |
| **Разъём** | Если моделируется стык платы и кабеля | 3D-модель в Analyst или S-параметрическая модель (Touchstone) |

#### Почему CLIN, а не TLIN

| Элемент | Порты | Что моделирует |
|---------|-------|---------------|
| **TLIN** | 2 (вход, выход) | Одиночная линия передачи. **Не подходит** — RS-485 дифференциальный, нужны два связанных проводника |
| **CLIN** | 4 (вход A, вход B, выход A, выход B) + 2 GND | Два электромагнитно связанных проводника. **Правильный выбор** — задаёт дифференциальный и синфазный импедансы, коэффициент связи |

## 3. Пошаговая инструкция по созданию модели в AWR DE 17

Инструкция разделена на **три части**: circuit-level модель (3.1), EM-модель (3.2), визуализация поля (3.3). Каждая часть — самостоятельна, но для полной работы нужны все три.

### Часть 3.1. Circuit-level модель (Microwave Office)

#### Шаг 1. Создание проекта

1. Запустите AWR Design Environment 17.
2. **File → New Project** (или **Ctrl+N**).
3. **File → Save Project As...** → имя: `RS485_Model` → **Save**.

Тип проекта выбирать не нужно — AWR DE 17 создаёт единый проект, в котором могут сосуществовать схемы, EM-структуры и графики.

#### Шаг 2. Создание схемы

1. В дереве проекта (Project Browser, левая панель) найдите раздел **Circuit Schematics**.
2. Правой кнопкой мыши → **New Schematic** → имя: `RS485_Base` → **OK**.

Откроется пустой лист схемы — Schematic Editor.

#### Шаг 3. Размещение CLIN

1. В Elements Browser (правая панель или **Draw → Add Element...**):
   - Путь: **Circuit Elements → Transmission Lines → Coupled Lines → CLIN**.
   - Или: в поле поиска (Search) наберите `CLIN`.
2. Перетащите CLIN на центр схемы.
3. Дважды щёлкните по элементу CLIN → откроется **Element Options**:
   - **ZE** (Z0E, импеданс чётной моды): `90`
   - **ZO** (Z0O, импеданс нечётной моды): `60`
   - **EL** (электрическая длина): `60`
   - **F0** (опорная частота): `0.005` (в ГГц, т.е. 5 МГц)
4. Нажмите **OK**.

**Расположение выводов CLIN:**
```
Pin 1 (вход A)  ────┐              ┌──── Pin 3 (выход A)
                     │     CLIN     │
Pin 2 (вход B)  ────┘              └──── Pin 4 (выход B)
                     │              │
                   GND_1          GND_2
```

**Физический смысл параметров:**

| Параметр | Значение | Что означает | Как связан с RS-485 |
|----------|----------|--------------|---------------------|
| Z0E = 90 Ом | Импеданс чётной моды | Когда оба проводника имеют одинаковый потенциал относительно земли (синфазный режим) | Zcomm = Z0E/2 = 45 Ом |
| Z0O = 60 Ом | Импеданс нечётной моды | Когда потенциалы проводников равны по модулю, но противоположны по знаку (дифференциальный режим) | Zdiff = 2×Z0O = 120 Ом — стандарт RS-485 |
| EL = 60° | Электрическая длина при F0 | Фазовый набег сигнала на опорной частоте. 60° при 5 МГц → физическая длина ~6.6 м | Определяет задержку в линии |
| F0 = 0.005 ГГц | Опорная частота | Частота, при которой EL = 60°. Задаётся в ГГц! | 5 МГц — основная гармоника RS-485 при 10 Мбит/с |

#### Шаг 4. Заземление CLIN

1. Добавьте 2 элемента **GND**: **Circuit Elements → Ports → GND** (или кнопка Ground на панели).
2. Инструмент провод: **Draw → Wire** или клавиша **W**.
3. Подключите GND к обоим нижним (земляным) выводам CLIN.

Без этого шага симуляция выдаст ошибку «Floating node».

#### Шаг 5. Добавление 4 портов

**PORT1** (вход линии A):
1. **Circuit Elements → Ports → PORT** → разместите слева от Pin 1 CLIN.
2. Дважды щёлкните → свойства: **PRT:** `1`, **Z:** `60`.
3. Проводом соедините PORT1 → Pin 1 CLIN.

**PORT2** (вход линии B):
1. PORT → слева от Pin 2.
2. Свойства: **PRT:** `2`, **Z:** `60`.
3. Соедините PORT2 → Pin 2 CLIN.

**PORT3** (выход линии A):
1. PORT → справа от Pin 3.
2. Свойства: **PRT:** `3`, **Z:** `60`.
3. Соедините Pin 3 → PORT3.

**PORT4** (выход линии B):
1. PORT → справа от Pin 4.
2. Свойства: **PRT:** `4`, **Z:** `60`.
3. Соедините Pin 4 → PORT4.

**Критически важно: все 4 порта должны иметь Z = 60 Ом.** Это Z0O линии, и именно при таком значении линия согласована. Если задать Z = 50 Ом, 120 Ом или 1 МОм — S-параметры будут искажены артефактами нормировки.

#### Шаг 6. Проверка схемы

Итоговая схема:
```
PORT1 (Z=60) ──── Pin1 ──┐              ┌── Pin3 ──── PORT3 (Z=60)
                          │     CLIN     │
PORT2 (Z=60) ──── Pin2 ──┘              └── Pin4 ──── PORT4 (Z=60)
                          │              │
```

#### Шаг 2. Настройка Stackup (подложка / слои)

В окне EM Structure найдите панель **Stackup** (внизу или сбоку, или **View → Enclosure**, или двойной щелчок по пустой области → вкладка **Stackup**).

Настройте слои **снизу вверх**:

**Слой 1: Ground Plane (земля)**
- Тип: Conductor / Ground
- Материал: Copper или PEC (Perfect Electric Conductor)
- Толщина: `0.035` мм (или 0 для идеального проводника)
- Это нижняя сторона платы — опорная земляная плоскость

**Слой 2: Dielectric (FR-4)**
- Тип: Dielectric
- Er (диэлектрическая проницаемость): `4.6`
- Tand (тангенс угла потерь): `0.02`
- Толщина (Height/H): `1.5` мм

**Слой 3: Top Metal (сигнальные проводники)**
- Тип: Conductor / Metal
- Материал: Copper
- Толщина: `0.035` мм (35 мкм = 1 oz/ft²)
- На этом слое будут нарисованы дорожки A и B

Итоговый Stackup:
```
┌─────────────────────────────────┐
│     Top Metal (Cu, 35 мкм)      │  ← проводники A и B здесь
├─────────────────────────────────┤
│     FR-4 (εr=4.6, H=1.5 мм)    │  ← диэлектрик
├─────────────────────────────────┤
│     Ground Plane (Cu/PEC)       │  ← земля, φ = 0
└─────────────────────────────────┘
```

**Почему именно такой Stackup:**
- Это стандартная двухслойная плата. Сигналы на верхнем слое, земля на нижнем.
- FR-4 с εr=4.6 — наиболее распространённый материал для RS-485.
- Толщина 1.5 мм — стандарт для двухслойных плат.
- 35 мкм меди — стандартная фольга 1 oz.

| Параметр | Microstrip (микрополоск) | Stripline (полосковая) |
|----------|-------------------------|----------------------|

## 4. Как правильно выбрать частотный диапазон для RS-485

### 4.1. Почему нельзя ограничиться скоростью передачи

RS-485 имеет максимальную скорость **10 Мбит/с**. Может показаться, что достаточно моделировать на частоте 10 МГц. Это **неправильно**.

**Причина:** цифровой сигнал — не синусоида. Прямоугольный импульс содержит гармоники, которые простираются **далеко за пределы** битовой частоты. Именно высшие гармоники определяют:
- Форму фронтов и спадов сигнала.
- Перекрёстные помехи (crosstalk) между дорожками.
- Излучение и восприимчивость к помехам (EMC/EMI).
- Качество передачи данных (jitter, eye diagram).

### 4.2. Как выбрать верхнюю частоту по фронту сигнала

Верхняя частота симуляции определяется **временем нарастания (rise time)** сигнала, а не битовой частотой.

**Формула:**

```
f_max = 0.35 / t_rise
```

или более консервативно (для 5-й гармоники):

```
f_max = 1 / (π × t_rise)
```

где t_rise — время нарастания фронта сигнала от 10% до 90%.

### 4.3. Пример инженерной оценки для RS-485

| Параметр | Типичное значение | Источник |
|----------|-------------------|----------|
| Битовая скорость | 10 Мбит/с | Стандарт RS-485, максимум |
| Период бита | 100 нс | 1 / 10 МГц |
| Время нарастания t_rise | 10–30 нс | Типично для драйверов RS-485 (SN75176, MAX485). Зависит от конкретной микросхемы |
| **f_max (для t_rise = 30 нс)** | **0.35 / 30e-9 ≈ 12 МГц** | Минимальный разумный диапазон |
| **f_max (для t_rise = 10 нс)** | **0.35 / 10e-9 = 35 МГц** | Для быстрых драйверов |
| **f_max (с запасом ×3)** | **100 МГц** | Инженерная практика: запас ×3 от f_max |

**Рекомендуемый диапазон для симуляции: 1 МГц — 100 МГц.**

Обоснование:
- Нижняя граница 1 МГц: ниже — модель ведёт себя как постоянный ток, нет интересных эффектов.
- Верхняя граница 100 МГц: покрывает все значимые гармоники сигнала RS-485 даже при самых быстрых фронтах.
- Если скорость ниже 10 Мбит/с (например, 9600 бод): t_rise ≈ 1–10 мкс → f_max ≈ 0.35–3.5 МГц. Но даже в этом случае моделирование до 100 МГц полезно для оценки EMC.

### 4.4. Частотный диапазон для EM-симуляции

Для EM-модели (AXIEM/Analyst):
- **Минимум:** 5 МГц (основная частота).
- **Максимум:** 100 МГц (запас).
- **Шаг:** 5 МГц (20 точек — достаточно для плавных кривых).
- **Для визуализации E-field:** одна точка — 5 МГц (ускоряет расчёт).

## 5. Как получить распределение электрического поля

### 5.1. Честное объяснение

**AWR DE 17 не выводит скалярное поле электрического потенциала φ(x,y,z) как отдельную величину.** Ни AXIEM, ни Analyst не имеют режима «Potential Distribution».

Однако AWR выводит **электрическое поле E(x,y,z)**, которое связано с потенциалом:

```
E = −∇φ    (электрическое поле — минус градиент потенциала)
```

Это означает:
- Карта |E| показывает, **где потенциал меняется быстрее всего** (максимальный градиент).
- Направление вектора E — от высокого потенциала к низкому.
- Линии E **перпендикулярны** эквипотенциальным поверхностям.
- Из карты E можно **однозначно восстановить** качественную картину потенциала.

**Вывод: карта E-field — это корректный и физически полный результат**, из которого следует распределение потенциала.

### 5.2. Где смотреть E-field: Analyst vs AXIEM

| Что доступно | Analyst (3D FEM) | AXIEM (2.5D MoM) |
|-------------|-----------------|-------------------|
| E-field (|E|, Ex, Ey, Ez) в объёме | **Да**, полная 3D-визуализация | **Нет** |
| E-field (Vector) в пространстве | **Да**, стрелки + color map | **Нет** |
| Current Density (J) на поверхности | **Да** | **Да** |
| H-field в объёме | **Да** | **Нет** |
| Поперечное сечение полей | **Да** (любая плоскость) | **Нет** |

**Для визуализации E-field нужен Analyst.**

### 5.3. Пошаговая инструкция: визуализация E-field в Analyst

#### Шаг 1. Убедитесь, что EM-симуляция завершена

После нажатия F8 в Output Window должно быть сообщение о завершении без ошибок.

#### Шаг 2. Откройте Field Viewer

1. В дереве проекта раскройте **EM Structures → RS485_DiffPair**.
2. Найдите подраздел **Fields** (или **Field Results**, **3D View**).
   - Или: правой кнопкой по `RS485_DiffPair` → **View 3D** / **View Fields** / **Analyst Field Viewer**.
   - Или: после симуляции автоматически появляется вкладка 3D-вида.
3. Откроется окно визуализации — 3D-представление структуры.

#### Шаг 3. Выберите тип поля

В панели инструментов Field Viewer:

1. **Тип поля:** выберите **E-Field (Electric Field)**.
2. **Компонент:** выберите **Magnitude (|E|)** — модуль вектора.
   - Альтернативы: Ex, Ey, Ez (отдельные компоненты), Vector (стрелки).
3. **Частота:** `5 МГц` (0.005 ГГц) — или интересующая вас частота.
4. **Порт возбуждения:** `Port 1` (или дифференциальный режим, если настроен).

#### Шаг 4. Построение поперечного сечения (Cross-Section)

Для карты распределения поля / потенциала наиболее информативно **поперечное сечение** — плоскость, перпендикулярная проводникам.

1. В Field Viewer найдите опцию **Cross-Section** / **Slice** / **Cut Plane**.
2. Выберите плоскость: **XZ** (если дорожки идут вдоль Y).
3. Задайте позицию сечения: **Y = 16 мм** (середина дорожек: 1 + 30/2 = 16 мм).
4. На сечении отобразится **цветовая карта (color map)**:
   - **Красный / яркий** → высокая напряжённость E → большой градиент потенциала.
   - **Синий / тёмный** → низкая напряжённость E → потенциал почти постоянен.

#### Шаг 5. Что вы должны увидеть

```
          Воздух (E ≈ 0, φ ≈ const)
    ─────────────────────────────────────
    
     ┌─────┐  зазор S=0.2мм  ┌─────┐
     │  A  │  ◄── MAX |E| ──►│  B  │       ← Top Metal
     │ (+V)│   (красная       │(−V) │
     └─────┘   область)       └─────┘
    ═══════════════════════════════════   ← FR-4 (εr=4.6)
    │   E существует: от каждого    │       E направлен вниз к земле
    │   проводника к Ground Plane   │
    ═══════════════════════════════════   ← Ground Plane (φ = 0)
```

**Между проводниками A и B:** максимум |E|. Здесь потенциал изменяется от +V (проводник A) до −V (проводник B) на расстоянии S = 0.2 мм. Это дифференциальный сигнал RS-485.

**Под каждым проводником (в FR-4):** E направлен вниз к земле. Потенциал изменяется от ±V (проводник) до 0 (земля) на расстоянии H = 1.5 мм.

**Далеко от проводников:** E → 0. Потенциал ≈ 0 (потенциал земли).

**На поверхности проводников:** граничное условие: φ = +V на A, φ = −V на B, φ = 0 на Ground.

#### Шаг 6. Векторное отображение (силовые линии)

1. В настройках визуализации выберите **Vector plot** (Arrow plot) для E-field.
2. Стрелки покажут направление E:
   - От A (+) к B (−) — горизонтально в зазоре.
   - От каждого проводника вниз к земле — вертикально в FR-4.
3. **Силовые линии E перпендикулярны эквипотенциальным поверхностям.** Мысленно проводя линии ⊥ стрелкам E, получаем эквипотенциали.

#### Шаг 7. Как выбрать частоту для визуализации

На **низких** частотах (5 МГц) структура поля определяется геометрией (квазистатический режим). Это оптимально для визуализации потенциала.

На **высоких** частотах (50–100 МГц) могут появиться волновые эффекты (неравномерность поля вдоль линии). Это интересно для анализа, но менее наглядно для распределения потенциала.

**Рекомендация:** визуализируйте на **5 МГц** (основной результат) и на **50 МГц** (для сравнения).

### 5.4. Как понять, что результат физически правдоподобен

| Критерий | Ожидание | Если не выполняется |
|----------|----------|---------------------|
| Максимум |E| — между проводниками A и B | Красная область в зазоре | Проверить дифференциальное возбуждение |
| |E| значительно в FR-4 под проводниками | Цвет в области между дорожками и землёй | Проверить Stackup — должен быть слой FR-4 |
| |E| ≈ 0 далеко от проводников | Синяя/тёмная область по краям | Если нет — Enclosure слишком маленький |
| Симметрия поля относительно оси между A и B | Зеркальная картина | Если нет — разный импеданс портов или разная геометрия дорожек |
| E направлен от A к B (в зазоре) и от проводников к земле (в FR-4) | Стрелки вектора E | Если наоборот — перепутана полярность портов |

### 5.5. Как интерпретировать результаты E-field

**Максимум поля между проводниками:**
- |E|_max ≈ ΔV / S, где ΔV — дифференциальное напряжение, S — зазор.
- Для ΔV = 5 В (типичное для RS-485) и S = 0.2 мм: |E| ≈ 5/0.2e-3 = 25 кВ/м.
- Это нормальное значение, далёкое от пробоя FR-4 (≈20 МВ/м).

**Асимметрия поля:**
- Если поле несимметрично относительно линии между A и B — причина: разная ширина дорожек, разный импеданс портов, геометрическая ошибка.
- В корректной модели поле должно быть **зеркально-антисимметричным** (E от +V к −V).

**Утечки поля (fringing):**
- Поле «вытекает» из зазора в стороны — это нормальное поведение микрополоска.
- Чем шире зазор S, тем больше fringing.
- Fringing определяет эффективную диэлектрическую проницаемость и, следовательно, реальный импеданс.

### 5.6. Дифференциальное возбуждение для корректной визуализации

Для корректной картины поля RS-485 нужно возбудить структуру **дифференциально**: Port 1 и Port 2 в противофазе.

**Способ 1: Mixed-Mode / Port Grouping**
1. В опциях EM Structure → **Port** / **Port Setup** / **Port Grouping**.
2. Определите пары:
   - Пара 1 (вход): Port 1 (+), Port 2 (−)
   - Пара 2 (выход): Port 3 (+), Port 4 (−)
3. Визуализируйте поле при возбуждении дифференциального порта D1.

**Способ 2: Differential Port**
В Analyst: при добавлении порта выберите тип **Differential** / **Lumped Port**:
- Positive terminal = проводник A
- Negative terminal = проводник B

**Способ 3: Ручная интерпретация**
Если mixed-mode недоступен: визуализируйте поле при возбуждении Port 1 отдельно. Поле от одного порта уже показывает основную структуру — поле от проводника A к земле. При Port 1+Port 2 в противофазе картина усиливается в зазоре.

### 5.7. Если доступен только AXIEM

1. Получите S-параметры из AXIEM — они будут корректны.
2. Визуализируйте **Current Density** (распределение тока):
   - Правой кнопкой по EM Structure → **View Current Density** / **Animate Currents**.
   - Покажет концентрацию тока на внутренних краях дорожек (обращённых друг к другу) — характерный признак дифференциального режима.
3. Для E-field в отчёте используйте аналитическое описание (см. Приложение А).

## 6. Проверка корректности модели

### 6.1. Критерии для circuit-level модели (CLIN)

| № | Критерий | Ожидаемый результат | Что означает | Если не выполняется |
|---|----------|---------------------|--------------|---------------------|
| 1 | DB(S[3,1]), все порты 60 Ом | ≈ 0 дБ (от 0 до −0.5 дБ) | Сигнал проходит без потерь | Проверить Z всех портов = 60 Ом |
| 2 | DB(S[1,1]), все порты 60 Ом | < −20 дБ | Нет отражений, согласование идеальное | Проверить Z0O = 60 Ом и Z портов = 60 Ом |
| 3 | DB(S[3,1]) = DB(S[4,2]) | Совпадают | Обе линии симметричны | Проверить симметрию CLIN (Z0E, Z0O) |

| 7 | DB(S[3,2]) ≠ −∞ | Есть перекрёстная связь | CLIN — связанные линии | Если S[3,2] = −∞ — Z0E = Z0O (нет связи) |

### 6.2. Критерии для EM-модели (AXIEM/Analyst)

| № | Критерий | Ожидание | Комментарий |
|---|----------|----------|-------------|
| 1 | Симуляция завершается без ошибок | Нет сообщений об ошибках | Порты подключены, геометрия корректна |
| 2 | DB(S[3,1]) | ≈ 0 ... −3 дБ | Небольшие потери из-за Tand FR-4 — это нормально |
| 3 | DB(S[1,1]) | < −10 дБ | Хорошее согласование |
| 4 | DB(S[3,1]) ≈ DB(S[4,2]) | Совпадают | Симметрия дорожек |
| 5 | E-field максимален между проводниками | Видно на сечении | Дифференциальное поле корректно |
| 6 | E-field в FR-4 под проводниками | Видно на сечении | Микрополосковая структура работает |
| 7 | E-field ≈ 0 далеко от структуры | Синяя область по краям | Граничные условия корректны |

### 6.3. Дифференциальный импеданс

Проверьте через TXLine (**Tools → TXLine**):
1. Выберите **Coupled Microstrip**.
2. Введите: Er=4.6, H=1.5 мм, T=0.035 мм, W=0.3 мм, S=0.2 мм.
3. Нажмите **Analyze**.
4. TXLine покажет Z0E, Z0O, Zdiff, Zcomm, εeff.
5. Zdiff должен быть в диапазоне **80–140 Ом**. Если нет — скорректируйте W и S.

### 6.4. Проверочные эксперименты

**Эксперимент 1: изменение зазора S**
- Увеличьте S с 0.2 мм до 1.0 мм.
- **Ожидание:** E между проводниками уменьшается, S[3,2] (crosstalk) уменьшается, Zdiff растёт.

**Эксперимент 2: изменение ширины W**
- Увеличьте W с 0.3 мм до 1.0 мм.
- **Ожидание:** поле распределяется шире, Zdiff уменьшается.

**Эксперимент 3: удаление Ground Plane**
- Удалите/отключите Ground в Stackup.
- **Ожидание:** структура поля кардинально меняется — нет вертикальных линий E к земле, только горизонтальные между A и B.

**Эксперимент 4: несогласованная нагрузка**
- Z PORT3 = Z PORT4 = 500 Ом.
- **Ожидание:** S[1,1] осциллирует (стоячие волны), E-field неравномерен вдоль линии.

### 6.5. Влияние терминатора 120 Ом

В circuit-level модели C (с явным R_term = 120 Ом):
- С R_term: DB(S[1,1]) < −10 дБ, слабая зависимость от частоты.
- Без R_term: DB(S[1,1]) осциллирует с пиками до ~0 дБ.
- Это наглядно демонстрирует необходимость терминации в RS-485.

### 6.6. Что должно насторожить

| Результат | Проблема |
|-----------|----------|
| DB(S[3,1]) = −70...−120 дБ | **Импедансы портов неправильные** (типично: Z = 1 МОм вместо 60 Ом) |
| DB(S[3,1]) > +1 дБ | Усиление в пассивной цепи — физически невозможно. Ошибка в модели |
| S[3,1] = S[4,2] = 0 дБ, S[3,2] = −∞ дБ, фаза = 0 | CLIN имеет EL = 0 или Z0E = Z0O — вырожденная модель |
| S[1,1] = 0 дБ на всех частотах | Полное отражение — линия не подключена или EL = 0 |
| E-field однородно по всей области | Неправильный Stackup или нет проводников |
| E-field только под одним проводником | Нет дифференциального возбуждения — проверить порты |

## 7. Типовые ошибки

### 7.1. PORT3/PORT4 с Z = 1 МОм (самая частая ошибка!)

**Симптом:** DB(S[3,1]) = −70...−120 дБ, что выглядит как «сигнал не проходит через линию».

**Причина:** S-параметры нормируются к импедансу порта. Формально S[3,1] = b₃/a₁, где b₃ ∝ 1/√Z₃. При Z₃ = 1 МОм коэффициент √(Z₁/Z₃) = √(60/10⁶) ≈ 0.008, что даёт −42 дБ **только из-за разницы нормировки**, до учёта реальных потерь.

**Исправление:** PORT3 = PORT4 = **60 Ом** (= Z0O).

### 7.2. Отсутствие правильной опорной плоскости (Ground Plane)

**В circuit-level модели:**
- Симптом: ошибка «Floating node» при запуске.
- Причина: земляные выводы CLIN не подключены.
- Исправление: подключить оба GND-вывода CLIN к элементу GND.

**В EM-модели:**
- Симптом: S-параметры абсурдны, E-field распределено хаотично.
- Причина: в Stackup нет Ground Plane или он на неправильном слое.
- Исправление: Ground Plane на нижнем слое (под диэлектриком).

### 7.3. Неправильные порты в EM Structure

**Симптом:** «Port not connected» или EM-симуляция не запускается.

**Причины:**
- Порт не касается торца проводника.
- Порт размещён на неправильном слое.
- Порт слишком далеко от проводника.

**Исправление:** точно совместить Edge Port с торцом дорожки. Port должен быть на том же слое, что и проводник.

### 7.4. Неверная геометрия дифференциальной пары

**Симптом:** Zdiff сильно отличается от 120 Ом; S-параметры не соответствуют ожиданиям.

**Причины:**
- W и S не рассчитаны через TXLine.
- Дорожки пересекаются или касаются.
- Дорожки на разных слоях.

**Исправление:** использовать TXLine для расчёта W и S; проверить, что обе дорожки на одном слое.

### 7.5. Отсутствие согласования (нет терминатора)

**Симптом:** S[1,1] осциллирует, передача неравномерна.

**Это не ошибка модели** — это реальная физика. Но если вы ожидали ровный S[3,1], проверьте, что порты имеют правильный импеданс (60 Ом для базовой модели, или 120 Ом R_term для полной модели).

### 7.6. Слишком грубая сетка (mesh) в EM-модели

**Симптом:** артефакты на карте E-field, «ступенчатое» поле, S-параметры не сходятся при увеличении числа частотных точек.

**Исправление:** увеличить Mesh Density с Normal до Fine. Или увеличить Cells per wavelength (для AXIEM).

### 7.7. Неверный Stackup

**Симптом:** импеданс дорожек не соответствует ожиданиям; поле распределено неправильно.

**Типичные ошибки:**
- H (толщина FR-4) задана в мм, но ввели в мкм.
- Er задан неправильно (например, 1.0 вместо 4.6 — воздух вместо FR-4).
- Нет слоя диэлектрика между Ground и Metal.
- T (толщина меди) задана в мм, но ввели в метрах.

**Исправление:** тщательно проверить единицы всех параметров Stackup.

### 7.8. Попытка моделировать «протокол» вместо физической структуры

**Симптом:** пользователь ищет в AWR элемент «RS-485 driver» или «UART transmitter».

**Суть проблемы:** AWR — не SPICE-симулятор и не HDL-среда. AWR моделирует **физику** (поля, импедансы, S-параметры). Драйвер RS-485 в AWR заменяется портом с импедансом + резистором (выходное сопротивление). Приёмник — резистором + ёмкостью.

### 7.9. F0 задана в МГц вместо ГГц

**Симптом:** линия ведёт себя как в 1000 раз короче; задержка ≈ 0.

**Причина:** в AWR DE 17 частоты задаются в **ГГц**. 5 МГц = **0.005** ГГц. Если ввести F0 = 5, AWR интерпретирует это как 5 ГГц.

### 7.10. DB(Ang(S[...])) — логарифм от фазы

**Симптом:** график показывает значения 200–230 — бессмысленные числа.

**Причина:** выбрана комбинация DB + Ang. DB(Ang(S)) = 20×log₁₀(фаза в градусах). Фаза 100°→170° → DB = 40...45. Это не имеет физического смысла.

**Правило:** для амплитуды — `DB(S[...])`, для фазы — `Ang(S[...])`. **Никогда** не комбинируйте DB и Ang.

### 7.11. Терминатор подключён к GND вместо между линиями

**Симптом:** R_term не улучшает S[1,1].

**Причина:** R_term = 120 Ом подключён от Pin 3 к GND (синфазная нагрузка), а не между Pin 3 и Pin 4 (дифференциальная нагрузка).

**Исправление:** R_term подключить **между** Pin 3 и Pin 4 CLIN.

### 7.12. Использование TLIN вместо CLIN

**Симптом:** только 2 порта, нет второй линии, невозможно задать дифференциальный импеданс.

**Причина:** TLIN — одиночная линия (2 порта), CLIN — связанная пара (4 порта + 2 GND). RS-485 требует CLIN.

### 7.13. Единицы ёмкости перепутаны

**Симптом:** C_rcv = 15 Ф вместо 15 пФ → КЗ на высоких частотах, S[3,1] резко падает.

**Проверка:** в AWR ёмкость по умолчанию в пФ. 15 пФ = 15 (без префикса) или 1.5e-11 Ф.

#### Материал подложки

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| **Материал** | FR-4 (стеклотекстолит) | Наиболее распространённый материал для плат RS-485. Дешёвый, доступный, достаточный для частот до 100 МГц |

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| **T (толщина фольги)** | 0.035 мм (35 мкм) | 1 oz/ft² — стандартная толщина медной фольги. 2 oz (70 мкм) используется для силовых цепей, для сигнальных достаточно 1 oz |
| **Rho (удельное сопротивление)** | 1 (нормировано к меди) | В AWR: Rho = 1 = медь. Rho > 1 = хуже меди. Медь — стандарт для PCB |

#### Геометрия дифференциальной пары

| Параметр | Значение | Обоснование |
|----------|----------|-------------|
| **W (ширина дорожки)** | 0.3 мм | Рассчитана через TXLine для Zdiff ≈ 100–130 Ом при H=1.5 мм на FR-4. Типична для дифференциальных пар. Минимальная технологичная ширина обычно 0.15 мм |
| **S (зазор между дорожками)** | 0.2 мм | Определяет степень связи и Zdiff. Чем меньше S, тем больше связь, тем ниже Zdiff. 0.2 мм — компромисс между связью и технологичностью |

| **Zdiff (целевой)** | ~120 Ом | Стандарт RS-485 (EIA/TIA-485). Точное значение зависит от W, S, H, Er — рассчитывается TXLine. Допуск ±10% (108–132 Ом) |

### 8.2. Что именно вы должны увидеть по E-field

На поперечном сечении (XZ, в середине линии):

1. **Яркая (красная) область** между проводниками A и B — максимум |E|. Ширина этой области ≈ S = 0.2 мм. Это зона максимального градиента потенциала — здесь потенциал скачком меняется от +V до −V.

2. **Менее яркие области** под каждым проводником (в FR-4) — поле E направлено к земле. Затухает по мере приближения к Ground Plane (расстояние H = 1.5 мм).

3. **Тёмная (синяя) область** далеко от проводников — |E| ≈ 0. Потенциал постоянен (= 0, потенциал земли).

4. **Характерная форма поля:** «грибок» или «колокол» вокруг каждого проводника с максимумом в зазоре. Это классическая картина связанных микрополосковых линий.

5. **На земляной плоскости:** E = 0 (на поверхности проводника), но J ≠ 0 (течёт обратный ток).

### 8.3. Численные оценки

| Величина | Оценка | Формула / источник |
|----------|--------|--------------------|
| Zdiff | ~100–130 Ом | TXLine (W=0.3, S=0.2, H=1.5, Er=4.6) |
| εeff (чётная мода) | ~3.5 | Зависит от W, H, Er |
| εeff (нечётная мода) | ~3.2 | Чуть ниже из-за поля в зазоре (частично в воздухе) |
| Скорость распространения | ~1.7×10⁸ м/с | c/√εeff |
| Задержка на 30 мм | ~0.18 нс | L/v = 30e-3 / 1.7e8 |
| |E|_max (между дорожками, при 5В) | ~25 кВ/м | ΔV/S = 5/0.2e-3 |
| Потери на 30 мм при 100 МГц | ~0.05 дБ | Малые при Tand=0.02 на такой длине |

## 9. Инструкция по печатной плате

### 9.1. AWR DE 17 как PCB-инструмент: честная оценка

**AWR DE 17 — не САПР печатных плат.** Это инструмент для СВЧ-проектирования и электромагнитного моделирования.

| Возможность | AWR DE 17 | Полноценный PCB CAD (Altium, KiCad, OrCAD) |

| Визуализация полей | **Да** (Analyst) | Нет |
| Создание Stackup | **Да** (в EM Structure) | Да |
| Размещение компонентов | **Нет** | Да |

### 9.2. Что можно сделать в AWR DE 17

#### Подготовка EM-модели участка платы (пошаговая инструкция)

Это то, что описано в части 3.2 — создание EM Structure с реальной геометрией.

1. **Создать EM Structure** с корректным Stackup (Ground → FR-4 → Metal).
2. **Нарисовать дифференциальную пару** (два прямоугольника с заданными W, S, L).
3. **Задать порты** на торцах дорожек.
4. **Рассчитать S-параметры** и **визуализировать поле**.
5. **Экспортировать S-параметры** в формат Touchstone (*.s4p):
   - Правой кнопкой по EM Structure → **Export** → **Touchstone**.
   - Этот файл можно импортировать в PCB CAD для использования как модель линии.

#### Layout в Microwave Office

Если в схеме используются элементы с физическими размерами (MCLIN, MLIN и т.д.):

1. **View → Layout** — откроется вид топологии.
2. Microwave Office покажет **геометрию дорожек** (ширина, длина, зазор).
3. Это **не полноценный PCB layout**, а визуализация RF-структуры.
4. Можно экспортировать: **File → Export** → **DXF** или **GDSII** — формат для передачи геометрии в другие CAD.

#### Экспорт геометрии из EM Structure

1. EM Structure → правой кнопкой → **Export**.
2. Форматы: DXF, GDSII, ODB++.
3. Экспортированную геометрию можно импортировать в PCB CAD для дальнейшей работы.

### 9.3. Правильный маршрут проектирования

Для полноценной PCB с RS-485 правильный workflow:

```
Шаг 1: AWR DE 17
├── Расчёт импедансов (TXLine): определить W, S для Zdiff=120 Ом
├── EM-модель (AXIEM/Analyst): проверить импеданс, потери, crosstalk
├── Визуализация E-field: понять структуру поля
├── Экспорт S-параметров (Touchstone .s4p)
└── Экспорт геометрии (DXF)

Шаг 2: PCB CAD (Altium / KiCad / OrCAD)
├── Импорт расчётных параметров из AWR (W, S, Stackup)
├── Создание схемы с реальными компонентами
├── Размещение компонентов
├── Трассировка дорожек с учётом W, S из AWR
├── DRC / DFM проверки
└── Генерация Gerber файлов для производства
```

### 9.4. Какие данные передать между AWR и PCB CAD

| Данные из AWR | Формат | Куда в PCB CAD |
|---------------|--------|----------------|
| W (ширина дорожки) | Число (мм) | Design rules → Differential pair width |
| S (зазор) | Число (мм) | Design rules → Differential pair gap |
| Stackup | Таблица параметров | PCB Stackup editor |
| S-параметры | Touchstone (.s4p) | Simulation / SI analysis |
| Геометрия | DXF / GDSII | Import → mechanical layer |
| Zdiff (расчётный) | Число (Ом) | Impedance constraints |

### 9.5. Подготовка Stackup для PCB

В AWR вы определили:
- Ground Plane (Cu, 35 мкм) — нижний слой.
- FR-4 (εr=4.6, H=1.5 мм) — диэлектрик.
- Top Metal (Cu, 35 мкм) — верхний слой.

В PCB CAD это транслируется как:

| Слой PCB | Материал | Толщина | Назначение |
|----------|----------|---------|------------|
| Top Copper | Cu | 35 мкм | Сигнальные дорожки (дифференциальная пара RS-485) |
| Core | FR-4 | 1.5 мм | Изоляция |
| Bottom Copper | Cu | 35 мкм | Сплошная земляная плоскость |

### 9.6. Ограничения AWR как PCB-инструмента

1. **Нельзя создать полноценную PCB** — нет routing, placement, Gerber.
2. **Нельзя задать полигоны земли** как в PCB CAD — Ground Plane в AWR — это бесконечная плоскость (или размер Enclosure).
3. **Нельзя «развести» дифференциальную пару** с изгибами, переходами, разветвлениями — только прямые участки (прямоугольники).
4. **Нет библиотеки компонентов** — нельзя разместить микросхему драйвера, разъём и т.д.
5. **AWR оптимален для моделирования критических участков**, а не для полного дизайна платы.

### 10.5. Почему именно такая методика технически корректна

1. **Разделение на circuit-level и EM-модель** соответствует реальной инженерной практике. Circuit-level модель (CLIN) быстро проверяет базовые свойства линии передачи (импеданс, согласование, задержка). EM-модель (Analyst/AXIEM) даёт точные результаты с учётом реальной геометрии и материалов.

2. **CLIN для витой пары, MCLIN/EM Structure для дорожек** — правильное разделение. Витая пара — кабель с заданным Zdiff, его удобно моделировать абстрактно. Дорожки на плате — физическая структура с конкретными размерами, для них нужна EM-модель.

3. **E-field как аналог распределения потенциала** — физически корректно. Связь E = −∇φ однозначная. Карта |E| даёт полную информацию о градиенте потенциала, а направление E указывает от высокого потенциала к низкому.

4. **Analyst (3D FEM) для визуализации полей** — единственный корректный выбор в AWR. AXIEM (2.5D MoM) рассчитывает токи и S-параметры, но не решает уравнения Максвелла в полном объёме (только на поверхностях). Analyst решает в 3D и может визуализировать E/H в любой точке пространства.

5. **Частотный диапазон 1–100 МГц** обоснован расчётом по времени нарастания сигнала RS-485 (f_max = 0.35/t_rise). Это не произвольный выбор, а инженерная практика (стандарт IPC-2141, IBIS).

6. **Двухслойный Stackup (Ground — FR-4 — Signal)** — наиболее типичная конфигурация для RS-485 на платах. Земляная плоскость обеспечивает контролируемый импеданс и экранирование.

7. **Терминирующий резистор 120 Ом** — требование стандарта RS-485 (EIA/TIA-485-A, раздел 8). Подключается дифференциально (между линиями A и B), а не к земле.

8. **Проверочные эксперименты** (изменение S, W, удаление Ground, рассогласование) — стандартная методика параметрического анализа, показывающая чувствительность модели к входным параметрам и подтверждающая физическую адекватность результатов.

## Приложение А. Если Analyst недоступен (только AXIEM)

### Что можно получить

1. **S-параметры** — полностью аналогичны Analyst.
2. **Current Density (J)** — распределение тока на поверхности проводников:
   - Правой кнопкой по EM Structure → **View Current Density** / **Animate Currents**.
   - Цветовая карта: ток максимален на внутренних краях дорожек (обращённых друг к другу) — это характерный признак дифференциального режима.

### Как описать распределение поля без визуализации

В учебной работе:
> *Распределение электрического поля интерпретировано аналитически на основе результатов EM-моделирования (S-параметры и распределение тока) и теории связанных микрополосковых линий. Электрическое поле сконцентрировано преимущественно в зазоре между проводниками дифференциальной пары (дифференциальная мода, E = −∇φ) и в диэлектрике между проводниками и земляной плоскостью. Численное подтверждение: S-параметры EM-модели соответствуют расчётным, распределение тока демонстрирует концентрацию на внутренних краях проводников.*

## Приложение Е. Допущения, принятые в модели

Для полноты перечислим инженерные допущения, принятые в данной модели:

| Допущение | Обоснование |
|-----------|-------------|
| Витая пара моделируется как CLIN без потерь | Для кабеля ≤ 50 м на частотах ≤ 100 МГц потери < 3 дБ. CLIN — хорошее приближение |
| Скрутка витой пары не моделируется явно | CLIN задаёт связь через Z0E/Z0O — это эквивалент скрутки на уровне модальных импедансов |
| Драйвер представлен как PORT + R (50 Ом) | Реальный драйвер имеет более сложную выходную цепь, но для частотного анализа резистивная модель достаточна |
| Приёмник: R (12 кОм) параллельно C (15 пФ) | Упрощённая модель входа приёмника RS-485. Для точного моделирования нужны данные из datasheet конкретной микросхемы |
| FR-4 с εr = 4.6 и Tand = 0.02 | Типичные значения. Реальный FR-4 имеет разброс εr = 4.2–4.8 и зависимость от частоты. Для инженерной оценки — достаточно |
| Microstrip (а не stripline) | Выбор обоснован типичной двухслойной платой для RS-485 |
| Земляная плоскость — сплошная | В реальной плате могут быть разрывы. Сплошная земля — идеализация и одновременно рекомендация |
| Переходные отверстия не моделируются | При длине дорожки 30 мм на одном слое vias не нужны. Если бы был переход между слоями — via добавляют паразитную индуктивность |
| Разъём не моделируется | Разъём вносит неоднородность импеданса. Для базовой модели допустимо его не учитывать. Для точной модели — нужна S-параметрическая модель разъёма |
